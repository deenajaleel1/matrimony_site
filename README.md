# matrimony_site
# Matrimony Web Application 💍

A simple and functional matrimonial website built using Django. Users can register, update profiles, search for potential matches, and communicate through a basic chat feature.

---

 🚀 Features

- User Registration & Login
- Profile Creation & Edit
- Search for Matches based on Preferences
- Matchmaking based on:
  - Gender
  - District
  - Religion
  - Community
  - Marital Status
  - Financial Status
- View Match Details
- Basic Chat System
- Recent Chats List
- Profile Search (by name)
- Clean design using HTML/CSS

---

 🛠 Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS
- **Database**: SQLite3
- **Version Control**: Git & GitHub

---

 ⚠️ Important Notes

> 🔒 All data in the project (including user details) are fake and used only for testing purposes.

- The database (`db.sqlite3`) is removed from this repository to protect sample user data.
- You can create your own superuser and test locally by running:
  ```bash
  python manage.py migrate
  python manage.py createsuperuser
